# Project 1B

## Markdown

**outline:** A responsive one-page website introducing Markdown, including what it is, how it works, where it is used, and its pros and cons.<br>
**demo page:** https://k-e-r.github.io/web-dev-2-project1b/<br>

***

## Features

- Responsive mobile-first layout
- Hamburger menu for mobile screens
- Slide-out navigation menu
- Desktop sidebar navigation
- Smooth scrolling anchor links
- Section-based one-page structure

## Sections

- Technology Overview
- What is it?
- What does it do?
- Why would you use it?
- Where would you use it?
- Pros and Cons
- Demo

## Built With

- HTML
